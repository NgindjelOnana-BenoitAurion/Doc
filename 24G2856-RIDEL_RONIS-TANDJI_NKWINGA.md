Dans la réalisation de notre travail de groupe il m'a été confié les codes permettant d'inverser les éléments d'un tableau et le code servant a ressortir la médiane d'un tableau 


1-INVERSION DES ELEMENTS : 
  Ici j'ai utilisé un tableau de 100 entier et puis j'ai donné la possibilité a l'utilisateur de définir le nombre de valeur qui lui seront utile .Dans la suite du programme l'utilisateur rempli le tableau et le programme lui renvoie les éléments en commençant par le dernier élément entré.


2-MEDIANE TABLEAU :

  Ici le code récupère un ensemble d'éléments toujours regrouper dans un tableau.Ensuite le code s'occupe tout d'abord de trié les éléments du tableau par ordre croissant.
  Une fois le tableau trié la médiane représente l'élément au centre du tableau 
    -Si la taille du tableau est impair le code renvoie l'élément a l'indice (n+1)/2 où n represente le nombre d'éléments du tableau 
    -Si la taille du tableau est pair 
le code fait la somme de le résultat de la somme entre l'élément a l'indice (n+1+ n)
